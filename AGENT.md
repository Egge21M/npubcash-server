# AGENT.md

## Agent skills

### Issue tracker

Issues and specs are tracked in GitHub Issues on `Egge21M/npubcash-server`; external pull requests are not a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

The canonical labels are `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

This repository uses a single-context domain layout. See `docs/agents/domain.md`.
