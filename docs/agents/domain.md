# Domain Docs

This repository uses a single-context domain layout.

Before exploring or modifying the codebase:

- Read the root `CONTEXT.md` for canonical domain language.
- Read relevant decisions under `docs/adr/` when that directory exists.
- Proceed silently when either location does not yet exist.

Use glossary terms consistently and avoid synonyms explicitly discouraged by
the glossary. Surface any conflict with an existing ADR instead of silently
overriding it.
