# Issue tracker: GitHub

Issues and specs for this repository live in GitHub Issues on
`Egge21M/npubcash-server`. Use the `gh` CLI with
`--repo Egge21M/npubcash-server` for all operations.

## Conventions

- Create, read, comment on, label, and close issues with `gh issue`.
- Always specify `--repo Egge21M/npubcash-server`.
- When a skill says “publish to the issue tracker,” create a GitHub issue.
- When a skill says “fetch the relevant ticket,” read the GitHub issue and its comments.

## Pull requests as a triage surface

External pull requests are not a request or triage surface. Triage workflows
process GitHub Issues only.
